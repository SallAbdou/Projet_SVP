# Lot 0 · Socle du front : plan d'implémentation

> **Pour les agents :** sous-skill requis : superpowers:executing-plans (ou subagent-driven-development). Étapes en cases `- [ ]`.

**Objectif :** poser le socle commun dont dépendent tous les lots suivants : état partagé entre pages, données au format de n8n WF3, moteur de rendu qui ne casse plus la saisie, nav unique, page « Mon profil » et remise à zéro de démo.

**Architecture :** logique pure dans de petits fichiers testés avec `node --test` (`store.js`, `api.js`, `nav.js`), branchés sur le moteur maison. `boot.js` expose l'application (`window.__app`), émet un événement `pq:rendu` après chaque rendu et restaure focus, curseur et défilement. `nav.js` écoute cet événement et remplit `[data-nav]` dans chaque page.

**Stack :** HTML/CSS/JS sans build, ES5 dans les fichiers du site, `node --test "tests/*.test.js"`.

**Spec :** `docs/superpowers/specs/2026-11-17-front-roadmap-design.md` (lot 0, principe des adaptateurs, contrat n8n).

## Contraintes globales

- Aucune dépendance, aucun build, aucun appel réseau autre que les fichiers du site. Aucun travail côté back.
- Aucun tiret long dans le code, les textes et les commits. Bilingue FR/EN pour l'interface ; contenus des articles dans une seule langue.
- Cibles de 44 px au doigt, focus visibles, charte existante.
- Clés `localStorage` du site : `pq-store` (état partagé), `pq-layout` (bento), `pq-lang` (langue). Toute lecture ou écriture dans un `try`.
- Format des données de la fournée = réponse de WF3, champ pour champ : `{ etat, prenom, articles: [{ ref, rang, titre, url, source, feu, raisonFeu, axe, resume, pourToi, durabilite, propension, lienOffre }] }`, `etat` parmi `pret`, `attente`, `invalide`, `feu` parmi `vert`, `orange`, `rouge`.
- Correspondance d'affichage : `vert` = Tout chaud, `orange` = À pétrir, `rouge` = Rassis ; monétisation = `durabilite + propension + lienOffre` sur 15.
- Commits locaux sur `feat/lot0-socle`, message terminé par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Aucun push sans accord.

**Hors périmètre, reporté à son lot :** extraction en JSON des données du comptoir, du garde-manger et du fournil (elles seront réécrites aux lots 3 à 5) ; `auth.js` et l'état `attente` simulé (lot 1).

## Points de vigilance

1. `pq-store` abîmé ou d'une ancienne version : état initial, jamais de page blanche. Testé en tâche 1.
2. `localStorage` inaccessible : le site marche, rien n'est enregistré. Testé en tâche 1.
3. Réponse de fournée `attente`, `invalide` ou incomplète : message clair dans la page au lieu d'un plantage. Testé en tâche 2, vérifié dans le navigateur.
4. Bascule FR/EN depuis la nav : le focus reste sur le bouton pressé. Vérifié en tâche 4.
5. `?demo=reset` combiné à d'autres paramètres : seul `demo` disparaît de l'adresse. Testé en tâche 1.

### Tâche 1 : état partagé `store.js`

**Fichiers :** créer `store.js`, `demo.js`, `tests/store.test.js`.

**Interfaces produites** (`window.Store` dans le navigateur, `module.exports` sous Node, même enveloppe que `bento.js`) :
- `CLE = 'pq-store'`, `CLES_DEMO = ['pq-store', 'pq-layout', 'pq-lang']`
- `etatInitial(): Etat` = `{ version: 1, sauves: [], ignores: { date: '', refs: [] }, brouillons: {}, publies: [] }`
- `normaliserEtat(raw): Etat` (version différente de 1, non-objet ou champs du mauvais type : remplacés par leur valeur initiale, champ par champ)
- `charger(storage): Etat`, `enregistrer(storage, etat): boolean`
- `mettreDeCote(etat, article, maintenantIso): Etat` (article au format WF3 ; on garde `ref, titre, source, feu, url` + `savedAt` ; sans doublon par `ref`)
- `estDeCote(etat, ref): boolean`, `retirer(etat, ref): Etat`
- `ignorer(etat, ref, dateFournee): Etat` (si `dateFournee` change, la liste repart de zéro), `refsIgnorees(etat, dateFournee): string[]`
- `enregistrerBrouillon(etat, ref, texte): Etat`
- `publier(etat, article, maintenantIso): Etat` (ajoute `{ id: ref + '-' + maintenantIso, ref, titre, publieLe: maintenantIso, chiffres: null }`)
- `saisirChiffres(etat, id, chiffres): Etat` (champs `impressions, reactions, republications, commentaires, contacts`, entiers positifs ou nuls ; une valeur invalide laisse l'état inchangé)
- `reinitialiserDemo(storage): void` (supprime `CLES_DEMO`), `retirerParamDemo(search): string | null` (renvoie la nouvelle chaîne de recherche si `demo=reset` est présent, sinon `null`)
- Toutes les fonctions renvoient un nouvel objet sans muter l'entrée.

`demo.js` (non testé, 5 lignes) : au chargement, si `Store.retirerParamDemo(location.search)` n'est pas `null`, appeler `Store.reinitialiserDemo(localStorage)` dans un `try`, puis `history.replaceState` avec la nouvelle adresse.

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const S = require('../store.js');
const art = { ref: 'recA', rang: 1, titre: 'Titre A', url: 'https://a.fr', source: 'The Decoder', feu: 'vert' };
const T0 = '2026-10-30T08:00:00.000Z';

test('état initial', () => {
  assert.deepEqual(S.etatInitial(), { version: 1, sauves: [], ignores: { date: '', refs: [] }, brouillons: {}, publies: [] });
});

test('normaliserEtat répare champ par champ', () => {
  for (const raw of [null, 'x', { version: 2 }]) assert.deepEqual(S.normaliserEtat(raw), S.etatInitial());
  const e = S.normaliserEtat({ version: 1, sauves: 'non', ignores: { date: 3 }, brouillons: { recA: 'ok', recB: 4 }, publies: [] });
  assert.deepEqual(e.sauves, []);
  assert.deepEqual(e.ignores, { date: '', refs: [] });
  assert.deepEqual(e.brouillons, { recA: 'ok' });
});

test('mettre de côté, sans doublon, puis retirer', () => {
  let e = S.mettreDeCote(S.etatInitial(), art, T0);
  e = S.mettreDeCote(e, art, T0);
  assert.equal(e.sauves.length, 1);
  assert.deepEqual(e.sauves[0], { ref: 'recA', titre: 'Titre A', source: 'The Decoder', feu: 'vert', url: 'https://a.fr', savedAt: T0 });
  assert.equal(S.estDeCote(e, 'recA'), true);
  assert.equal(S.estDeCote(S.retirer(e, 'recA'), 'recA'), false);
});

test('ignorer vaut pour une seule fournée', () => {
  const e = S.ignorer(S.ignorer(S.etatInitial(), 'recA', '2026-10-30'), 'recB', '2026-10-30');
  assert.deepEqual(S.refsIgnorees(e, '2026-10-30'), ['recA', 'recB']);
  assert.deepEqual(S.refsIgnorees(e, '2026-10-31'), []);
  assert.deepEqual(S.ignorer(e, 'recC', '2026-10-31').ignores, { date: '2026-10-31', refs: ['recC'] });
});

test('brouillon, publication et chiffres', () => {
  let e = S.enregistrerBrouillon(S.etatInitial(), 'recA', 'Mon texte');
  assert.equal(e.brouillons.recA, 'Mon texte');
  e = S.publier(e, art, T0);
  assert.deepEqual(e.publies[0], { id: 'recA-' + T0, ref: 'recA', titre: 'Titre A', publieLe: T0, chiffres: null });
  const ch = { impressions: 1240, reactions: 52, republications: 7, commentaires: 9, contacts: 1 };
  e = S.saisirChiffres(e, 'recA-' + T0, ch);
  assert.deepEqual(e.publies[0].chiffres, ch);
  assert.deepEqual(S.saisirChiffres(e, 'recA-' + T0, Object.assign({}, ch, { reactions: -1 })), e);
  assert.deepEqual(S.saisirChiffres(e, 'inconnu', ch), e);
});

test('charger et enregistrer, y compris stockage cassé', () => {
  const mem = {};
  const st = { getItem: k => (k in mem ? mem[k] : null), setItem: (k, v) => { mem[k] = String(v); }, removeItem: k => { delete mem[k]; } };
  assert.deepEqual(S.charger(st), S.etatInitial());
  const e = S.mettreDeCote(S.etatInitial(), art, T0);
  assert.equal(S.enregistrer(st, e), true);
  assert.deepEqual(S.charger(st), e);
  mem['pq-store'] = '{cassé';
  assert.deepEqual(S.charger(st), S.etatInitial());
  const boom = { getItem() { throw new Error('x'); }, setItem() { throw new Error('x'); }, removeItem() { throw new Error('x'); } };
  assert.deepEqual(S.charger(boom), S.etatInitial());
  assert.equal(S.enregistrer(boom, e), false);
  assert.doesNotThrow(() => S.reinitialiserDemo(boom));
  mem['pq-layout'] = '1'; mem['pq-lang'] = 'en'; mem['autre'] = 'garde';
  S.reinitialiserDemo(st);
  assert.deepEqual(Object.keys(mem), ['autre']);
});

test('retirerParamDemo', () => {
  assert.equal(S.retirerParamDemo('?demo=reset'), '');
  assert.equal(S.retirerParamDemo('?a=1&demo=reset&b=2'), '?a=1&b=2');
  assert.equal(S.retirerParamDemo('?demo=autre'), null);
  assert.equal(S.retirerParamDemo(''), null);
});
```

### Tâche 3 : moteur de rendu qui garde la saisie

**Fichiers :** modifier `boot.js`.

**Interfaces produites :**
- `window.__app` : l'instance du composant de la page (pour `nav.js`).
- Après chaque rendu, dans cet ordre : écouteurs branchés, `document.dispatchEvent(new CustomEvent('pq:rendu', { detail: { root: root, lang: lang } }))`, `c.afterRender(root)` si présent, restauration du focus.
- Restauration : avant `innerHTML`, mémoriser la clé de l'élément actif dans `root` (son `id`, sinon son attribut `data-focus`, sinon `[data-act]` + `[data-id]`, sinon « balise + rang parmi les éléments de même balise dans `root` »), `selectionStart` / `selectionEnd` s'il s'agit d'un champ texte, et `window.scrollY`. Après le rendu : retrouver l'élément, `focus({ preventScroll: true })`, rétablir la sélection, rétablir le défilement de la fenêtre. Si l'élément n'existe plus : ne rien faire (`afterRender` de la page peut déjà avoir placé le focus ; dans ce cas ne pas l'écraser).
- Les pages qui veulent garder la valeur d'un champ la mettent dans leur état (`onInput`) : le moteur ne recopie pas les valeurs.

# Lot 13 Bronze Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Comptoir plus direct, scores de retour dans la fournée, bouton « Pétrir » en forme de pain, palette Bronze et quatre thèmes choisis dans le profil.

**Architecture:** Site statique sans build. Logique pure ES5 testée sous Node (`comptoir.js`, `bento.js`, nouveau `theme.js`), couleurs dans `charte.css` par variables de rôle redéfinies par `[data-theme]`. Le thème est posé sur `<html>` dans le `<head>` des pages protégées, avant le premier rendu.

**Tech Stack:** HTML, CSS, JavaScript ES5, moteur maison `dc.js` + `boot.js`, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-18-lot13-bronze-design.md`

## Global Constraints

- Aucun tiret long nulle part (code, textes, commits).
- Aucune dépendance ni build ; ES5 dans les fichiers de logique pure.
- Contraste ≥ 4,5:1 pour le texte, ≥ 3:1 pour les éléments graphiques, prouvé par `Charte.contraste` dans `tests/charte.test.js`, pour chacun des 4 thèmes.
- Cibles tactiles ≥ 44 px de haut, focus visible, animations coupées sous `prefers-reduced-motion`.
- Commits terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Pas de push.

## Review Focus

- Thème Nuit sur un texte posé sur un fond fixe clair (doré n°1, croûte jaune, puce À pétrir) : le texte doit rester sombre (`--sur-clair`), vérifié au navigateur en Nuit.
- Compte sans e-mail ni identifiant (session corrompue) : `Theme.cleCompte(null)` renvoie `null` et `lire` renvoie `bronze` (test).
- `pq-theme` illisible (JSON cassé, version inconnue, nom de thème inconnu) : `lire` renvoie `bronze` sans lever d'erreur (test).
- Stockage indisponible (navigation privée) : `enregistrer` renvoie `false` sans lever d'erreur, la page applique quand même le thème (test).
- Analyse avec moyenne des autres posts à 0 et verts > 0 : `chaudGagne` vaut `true` (test).
